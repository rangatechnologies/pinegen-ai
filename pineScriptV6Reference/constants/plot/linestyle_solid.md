# plot.linestyle_solid

**Category:** Constant

**Type:** `const plot_line_style`

## Description

A named constant for use with the [plot()](../../functions/plot.md) function's `linestyle` parameter, which modifies the appearance of plotted lines. If the `style` argument of the function call specifies a plot style that displays a line, using this constant as the `linestyle` argument specifies that the plotted line is solid.
