# polyline.all

**Category:** Variable

**Type:** `array<polyline>`

## Description

Returns an array containing all current [polyline](../../types/polyline.md) instances drawn by the script.

## Remarks

The array is read-only. Index zero of the array references the ID of the oldest polyline object on the chart.
