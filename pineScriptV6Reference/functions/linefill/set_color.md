# linefill.set_color

**Category:** Function

## Syntax

```pinescript
linefill.set_color(id, color) → void
```

## Description

The function sets the color of the linefill object passed to it.

## Arguments

- **`id`** `series linefill` — A linefill object.
- **`color`** `series color` — The color of the linefill object.

**Return type(s):** `void`
