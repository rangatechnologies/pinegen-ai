# linefill.get_line1

**Category:** Function

## Syntax

```pinescript
linefill.get_line1(id) → series line
```

## Description

Returns the ID of the first line used in the `id` linefill.

## Arguments

- **`id`** `series linefill` — A linefill object.

**Return type(s):** `series line`
