# math.sqrt

**Category:** Function

## Syntax

_4 overloaded forms:_

```pinescript
math.sqrt(number) → simple float
```

```pinescript
math.sqrt(number) → input float
```

```pinescript
math.sqrt(number) → const float
```

```pinescript
math.sqrt(number) → series float
```

## Description

Square root of any `number` >= 0 is the unique y >= 0 such that y^2 = `number`.

## Arguments

- **`number`** `simple int/float` — The number to use in the calculation.

## Returns

The square root of `number`.

**Return type(s):** `simple float`
