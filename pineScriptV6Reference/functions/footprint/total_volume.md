# footprint.total_volume

**Category:** Function

## Syntax

```pinescript
footprint.total_volume(id) → series float
```

## Description

Calculates the sum of the total "buy" volume and "sell" volume for the volume footprint represented by a [footprint](../../types/footprint.md) object.

## Arguments

- **`id`** `footprint` — The reference (ID) of the [footprint](../../types/footprint.md) object to analyze.

## Returns

The total volume measured by the footprint.

**Return type(s):** `series float`
