# volume_row.down_price

**Category:** Function

## Syntax

```pinescript
volume_row.down_price(id) → series float
```

## Description

Retrieves the lower price level of the volume footprint row represented by a [volume_row](../../types/volume_row.md) object.

## Arguments

- **`id`** `volume_row` — The reference (ID) of the [volume_row](../../types/volume_row.md) object to analyze.

## Returns

The lower boundary of the footprint row's price range.

**Return type(s):** `series float`
