# label.set_point

**Category:** Function

## Syntax

```pinescript
label.set_point(id, point) → void
```

## Description

Sets the location of the `id` label to `point`.

## Arguments

- **`id`** `series label` — A [label](../../types/label.md) object.
- **`point`** `chart.point` — A [chart.point](../../types/chart/point.md) object.

**Return type(s):** `void`
