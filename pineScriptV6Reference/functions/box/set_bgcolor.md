# box.set_bgcolor

**Category:** Function

## Syntax

```pinescript
box.set_bgcolor(id, color) → void
```

## Description

Sets the background color of the box.

## Arguments

- **`id`** `series box` — A box object.
- **`color`** `series color` — New background color.

**Return type(s):** `void`
