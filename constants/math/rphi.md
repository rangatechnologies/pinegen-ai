# math.rphi

**Category:** Constant

**Type:** `const float`

## Description

Is a named constant for the [golden ratio conjugate](https://en.wikipedia.org/wiki/Golden_ratio#Golden_ratio_conjugate). It is equal to 0.6180339887498948.
