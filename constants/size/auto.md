# size.auto

**Category:** Constant

**Type:** `const string`

## Description

A constant to specify the size of the graphics drawn by [plotchar()](../../functions/plotchar.md), [plotshape()](../../functions/plotshape.md), [label.new()](../../functions/label/new.md), and [box.new()](../../functions/box/new.md). Adjusts the size of the graphics automatically.
