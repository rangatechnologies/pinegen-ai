# size.tiny

**Category:** Constant

**Type:** `const string`

## Description

A constant to specify the size of the graphics drawn by [plotchar()](../../functions/plotchar.md), [plotshape()](../../functions/plotshape.md), [label.new()](../../functions/label/new.md), [box.new()](../../functions/box/new.md), and [table.cell()](../../functions/table/cell.md). Sets the size to tiny.
