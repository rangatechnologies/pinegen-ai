# display.none

**Category:** Constant

**Type:** `const plot_simple_display`

## Description

A named constant for use with the `display` parameter of the `plot*()`, `input*()`, [fill()](../../functions/fill.md), [bgcolor()](../../functions/bgcolor.md), [barcolor()](../../functions/barcolor.md), and [hline()](../../functions/hline.md) functions. Specifies that the values or visuals are not displayed anywhere by default.

## Remarks

Selecting a deselected plot in the script's "Settings/Style" tab changes its display settings, causing the plotted data to appear in all available chart locations. To restore the display settings coded in the script, select "Reset settings" from the "Defaults" dropdown menu at the bottom of the "Settings" dialog box.
