# format.percent

**Category:** Constant

**Type:** `const string`

## Description

Is a named constant for selecting the formatting of the script output values as a percentage in the indicator function. It adds a percent sign after values.

## Remarks

The default precision is 2, regardless of the precision of the chart itself. This can be changed with the 'precision' argument of the [indicator()](../../functions/indicator.md) function.
