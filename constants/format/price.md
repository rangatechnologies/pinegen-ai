# format.price

**Category:** Constant

**Type:** `const string`

## Description

Is a named constant for selecting the formatting of the script output values as prices in the [indicator()](../../functions/indicator.md) function.

## Remarks

If format is format.price, default precision value is set. You can use the precision argument of indicator function to change the precision value.
