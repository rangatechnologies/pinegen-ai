# strategy.long

**Category:** Constant

**Type:** `const strategy_direction`

## Description

A named constant for use with the `direction` parameter of the [strategy.entry()](../../functions/strategy/entry.md) and [strategy.order()](../../functions/strategy/order.md) commands. It specifies that the command creates a buy order.
