# chart.is_standard

**Category:** Variable

**Type:** `simple bool`

## Returns

Returns [true](../../constants/true.md) if the chart type is not one of the following: Renko, Kagi, Line break, Point & figure, Range, Heikin Ashi; [false](../../constants/false.md) otherwise.
