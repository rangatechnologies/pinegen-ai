# strategy.max_drawdown_percent

**Category:** Variable

**Type:** `series float`

## Description

The maximum equity drawdown value for the whole trading range, expressed as a percentage and calculated by formula: `Lowest Value During Trade / (Entry Price x Quantity) * 100`.
