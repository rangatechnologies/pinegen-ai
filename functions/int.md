# int

**Category:** Function

## Syntax

_4 overloaded forms:_

```pinescript
int(x) → simple int
```

```pinescript
int(x) → input int
```

```pinescript
int(x) → const int
```

```pinescript
int(x) → series int
```

## Description

Casts na or truncates float value to int

## Arguments

- **`x`** `simple int/float` — The value to convert to the specified type, usually [na](../variables/na.md).

## Returns

The value of the argument after casting to int.

**Return type(s):** `simple int`
