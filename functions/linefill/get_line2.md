# linefill.get_line2

**Category:** Function

## Syntax

```pinescript
linefill.get_line2(id) → series line
```

## Description

Returns the ID of the second line used in the `id` linefill.

## Arguments

- **`id`** `series linefill` — A linefill object.

**Return type(s):** `series line`
