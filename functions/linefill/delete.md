# linefill.delete

**Category:** Function

## Syntax

```pinescript
linefill.delete(id) → void
```

## Description

Deletes the specified linefill object. If it has already been deleted, does nothing.

## Arguments

- **`id`** `series linefill` — A linefill object.

**Return type(s):** `void`
