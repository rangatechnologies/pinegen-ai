# footprint.sell_volume

**Category:** Function

## Syntax

```pinescript
footprint.sell_volume(id) → series float
```

## Description

Calculates the total "sell" volume for the volume footprint represented by a [footprint](../../types/footprint.md) object.

## Arguments

- **`id`** `footprint` — The reference (ID) of the [footprint](../../types/footprint.md) object to analyze.

## Returns

The total "sell" volume measured by the footprint.

**Return type(s):** `series float`
