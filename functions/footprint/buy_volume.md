# footprint.buy_volume

**Category:** Function

## Syntax

```pinescript
footprint.buy_volume(id) → series float
```

## Description

Calculates the total "buy" volume for the volume footprint represented by a [footprint](../../types/footprint.md) object. 

## Arguments

- **`id`** `footprint` — The reference (ID) of the [footprint](../../types/footprint.md) object to analyze.

## Returns

The total "buy" volume measured by the footprint.

**Return type(s):** `series float`
