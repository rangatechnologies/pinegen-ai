# volume_row.up_price

**Category:** Function

## Syntax

```pinescript
volume_row.up_price(id) → series float
```

## Description

Retrieves the upper price level of the volume footprint row represented by a [volume_row](../../types/volume_row.md) object.

## Arguments

- **`id`** `volume_row` — The reference (ID) of the [volume_row](../../types/volume_row.md) object to analyze.

## Returns

The upper boundary of the footprint row's price range.

**Return type(s):** `series float`
