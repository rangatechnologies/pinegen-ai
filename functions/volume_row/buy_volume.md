# volume_row.buy_volume

**Category:** Function

## Syntax

```pinescript
volume_row.buy_volume(id) → series float
```

## Description

Calculates the total "buy" volume for the volume footprint row represented by a [volume_row](../../types/volume_row.md) object.

## Arguments

- **`id`** `volume_row` — The reference (ID) of the [volume_row](../../types/volume_row.md) object to analyze.

## Returns

The total "buy" volume for the footprint row.

**Return type(s):** `series float`
