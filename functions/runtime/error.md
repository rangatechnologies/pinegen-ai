# runtime.error

**Category:** Function

## Syntax

```pinescript
runtime.error(message) → void
```

## Description

When called, causes a runtime error with the error message specified in the `message` argument.

## Arguments

- **`message`** `series string` — Error message.

**Return type(s):** `void`
