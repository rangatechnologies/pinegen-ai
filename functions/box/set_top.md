# box.set_top

**Category:** Function

## Syntax

```pinescript
box.set_top(id, top) → void
```

## Description

Sets the top coordinate of the box.

## Arguments

- **`id`** `series box` — A box object.
- **`top`** `series int/float` — Price value of the top border.

**Return type(s):** `void`
