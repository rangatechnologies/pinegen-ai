# box.set_text

**Category:** Function

## Syntax

```pinescript
box.set_text(id, text) → void
```

## Description

The function sets the text in the box.

## Arguments

- **`id`** `series box` — A box object.
- **`text`** `series string` — The text to be displayed inside the box.

**Return type(s):** `void`
