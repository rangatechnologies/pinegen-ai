# box.set_border_color

**Category:** Function

## Syntax

```pinescript
box.set_border_color(id, color) → void
```

## Description

Sets the border color of the box.

## Arguments

- **`id`** `series box` — A box object.
- **`color`** `series color` — New border color.

**Return type(s):** `void`
