# box.get_top

**Category:** Function

## Syntax

```pinescript
box.get_top(id) → series float
```

## Description

Returns the price value of the top border of the box.

## Arguments

- **`id`** `series box` — A box object.

## Returns

The price value.

**Return type(s):** `series float`
