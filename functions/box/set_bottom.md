# box.set_bottom

**Category:** Function

## Syntax

```pinescript
box.set_bottom(id, bottom) → void
```

## Description

Sets the bottom coordinate of the box.

## Arguments

- **`id`** `series box` — A box object.
- **`bottom`** `series int/float` — Price value of the bottom border.

**Return type(s):** `void`
