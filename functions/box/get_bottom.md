# box.get_bottom

**Category:** Function

## Syntax

```pinescript
box.get_bottom(id) → series float
```

## Description

Returns the price value of the bottom border of the box.

## Arguments

- **`id`** `series box` — A box object.

## Returns

The price value.

**Return type(s):** `series float`
