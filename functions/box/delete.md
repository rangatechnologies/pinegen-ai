# box.delete

**Category:** Function

## Syntax

```pinescript
box.delete(id) → void
```

## Description

Deletes the specified box object. If it has already been deleted, does nothing.

## Arguments

- **`id`** `series box` — A box object to delete.

**Return type(s):** `void`
