# box.set_text_halign

**Category:** Function

## Syntax

```pinescript
box.set_text_halign(id, text_halign) → void
```

## Description

The function sets the horizontal alignment of the box's text.

## Arguments

- **`id`** `series box` — A box object.
- **`text_halign`** `series string` — The horizontal alignment of a box's text. Possible values: [text.align_left](../../constants/text/align_left.md), [text.align_center](../../constants/text/align_center.md), [text.align_right](../../constants/text/align_right.md).

**Return type(s):** `void`
