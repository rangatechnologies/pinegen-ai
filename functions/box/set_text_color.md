# box.set_text_color

**Category:** Function

## Syntax

```pinescript
box.set_text_color(id, text_color) → void
```

## Description

The function sets the color of the text inside the box.

## Arguments

- **`id`** `series box` — A box object.
- **`text_color`** `series color` — The color of the text.

**Return type(s):** `void`
