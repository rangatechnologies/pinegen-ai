# box.set_border_width

**Category:** Function

## Syntax

```pinescript
box.set_border_width(id, width) → void
```

## Description

Sets the border width of the box.

## Arguments

- **`id`** `series box` — A box object.
- **`width`** `series int` — Width of the four borders, in pixels.

**Return type(s):** `void`
