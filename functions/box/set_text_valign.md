# box.set_text_valign

**Category:** Function

## Syntax

```pinescript
box.set_text_valign(id, text_valign) → void
```

## Description

The function sets the vertical alignment of a box's text.

## Arguments

- **`id`** `series box` — A box object.
- **`text_valign`** `series string` — The vertical alignment of the box's text. Possible values: [text.align_top](../../constants/text/align_top.md), [text.align_center](../../constants/text/align_center.md), [text.align_bottom](../../constants/text/align_bottom.md).

**Return type(s):** `void`
