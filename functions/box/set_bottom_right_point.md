# box.set_bottom_right_point

**Category:** Function

## Syntax

```pinescript
box.set_bottom_right_point(id, point) → void
```

## Description

Sets the bottom-right corner location of the `id` box to `point`.

## Arguments

- **`id`** `series box` — A [box](../../types/box.md) object.
- **`point`** `chart.point` — A [chart.point](../../types/chart/point.md) object.

**Return type(s):** `void`
