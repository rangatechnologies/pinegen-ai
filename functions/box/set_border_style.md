# box.set_border_style

**Category:** Function

## Syntax

```pinescript
box.set_border_style(id, style) → void
```

## Description

Sets the border style of the box.

## Arguments

- **`id`** `series box` — A box object.
- **`style`** `series string` — New border style.

**Return type(s):** `void`
