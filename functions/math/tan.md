# math.tan

**Category:** Function

## Syntax

_4 overloaded forms:_

```pinescript
math.tan(angle) → simple float
```

```pinescript

```

```pinescript

```

## Description

The tan function returns the trigonometric tangent of an angle.

## Arguments

- **`angle`** `simple int/float` — Angle, in radians.

## Returns

The trigonometric tangent of an angle.

**Return type(s):** `simple float`
