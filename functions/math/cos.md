# math.cos

**Category:** Function

## Syntax

_4 overloaded forms:_

```pinescript
math.cos(angle) → simple float
```

```pinescript
math.cos(angle) → input float
```

```pinescript
math.cos(angle) → const float
```

```pinescript
math.cos(angle) → series float
```

## Description

The cos function returns the trigonometric cosine of an angle.

## Arguments

- **`angle`** `simple int/float` — Angle, in radians.

## Returns

The trigonometric cosine of an angle.

**Return type(s):** `simple float`
