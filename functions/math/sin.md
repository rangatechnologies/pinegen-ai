# math.sin

**Category:** Function

## Syntax

_4 overloaded forms:_

```pinescript
math.sin(angle) → simple float
```

```pinescript
math.sin(angle) → input float
```

```pinescript
math.sin(angle) → const float
```

```pinescript
math.sin(angle) → series float
```

## Description

The sin function returns the trigonometric sine of an angle.

## Arguments

- **`angle`** `simple int/float` — Angle, in radians.

## Returns

The trigonometric sine of an angle.

**Return type(s):** `simple float`
