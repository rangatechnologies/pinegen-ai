# label.set_textcolor

**Category:** Function

## Syntax

```pinescript
label.set_textcolor(id, textcolor) → void
```

## Description

Sets color of the label text.

## Arguments

- **`id`** `series label` — Label object.
- **`textcolor`** `series color` — New text color.

**Return type(s):** `void`
