# label.set_y

**Category:** Function

## Syntax

```pinescript
label.set_y(id, y) → void
```

## Description

Sets price of the label position

## Arguments

- **`id`** `series label` — Label object.
- **`y`** `series int/float` — New price of the label position.

**Return type(s):** `void`
