# label.set_color

**Category:** Function

## Syntax

```pinescript
label.set_color(id, color) → void
```

## Description

Sets label border and arrow color.

## Arguments

- **`id`** `series label` — Label object.
- **`color`** `series color` — New label border and arrow color.

**Return type(s):** `void`
