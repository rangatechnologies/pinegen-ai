# label.set_tooltip

**Category:** Function

## Syntax

```pinescript
label.set_tooltip(id, tooltip) → void
```

## Description

Sets the tooltip text.

## Arguments

- **`id`** `series label` — Label object.
- **`tooltip`** `series string` — Tooltip text.

**Return type(s):** `void`
