# label.set_textalign

**Category:** Function

## Syntax

```pinescript
label.set_textalign(id, textalign) → void
```

## Description

Sets the alignment for the label text.

## Arguments

- **`id`** `series label` — Label object.
- **`textalign`** `series string` — Label text alignment. Possible values: [text.align_left](../../constants/text/align_left.md), [text.align_center](../../constants/text/align_center.md), [text.align_right](../../constants/text/align_right.md).

**Return type(s):** `void`
