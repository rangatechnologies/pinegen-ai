# label.set_yloc

**Category:** Function

## Syntax

```pinescript
label.set_yloc(id, yloc) → void
```

## Description

Sets new y-location calculation algorithm.

## Arguments

- **`id`** `series label` — Label object.
- **`yloc`** `series string` — New y-location value.

**Return type(s):** `void`
