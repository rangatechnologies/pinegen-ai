# line.set_width

**Category:** Function

## Syntax

```pinescript
line.set_width(id, width) → void
```

## Description

Sets the line width.

## Arguments

- **`id`** `series line` — Line object.
- **`width`** `series int` — New line width in pixels.

**Return type(s):** `void`
