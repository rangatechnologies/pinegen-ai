# line.delete

**Category:** Function

## Syntax

```pinescript
line.delete(id) → void
```

## Description

Deletes the specified line object. If it has already been deleted, does nothing.

## Arguments

- **`id`** `series line` — Line object to delete.

**Return type(s):** `void`
