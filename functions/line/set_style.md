# line.set_style

**Category:** Function

## Syntax

```pinescript
line.set_style(id, style) → void
```

## Description

Sets the line style

## Arguments

- **`id`** `series line` — Line object.
- **`style`** `series string` — New line style.

**Return type(s):** `void`
