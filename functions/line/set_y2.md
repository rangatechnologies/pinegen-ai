# line.set_y2

**Category:** Function

## Syntax

```pinescript
line.set_y2(id, y) → void
```

## Description

Sets price of the second point.

## Arguments

- **`id`** `series line` — Line object.
- **`y`** `series int/float` — Price.

**Return type(s):** `void`
