# line.set_first_point

**Category:** Function

## Syntax

```pinescript
line.set_first_point(id, point) → void
```

## Description

Sets the first point of the `id` line to `point`.

## Arguments

- **`id`** `series line` — A [line](../../types/line.md) object.
- **`point`** `chart.point` — A [chart.point](../../types/chart/point.md) object.

**Return type(s):** `void`
