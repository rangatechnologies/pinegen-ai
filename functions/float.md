# float

**Category:** Function

## Syntax

_4 overloaded forms:_

```pinescript
float(x) → const float
```

```pinescript
float(x) → input float
```

```pinescript
float(x) → simple float
```

```pinescript
float(x) → series float
```

## Description

Casts na to float

## Arguments

- **`x`** `const int/float` — The value to convert to the specified type, usually [na](../variables/na.md).

## Returns

The value of the argument after casting to float.

**Return type(s):** `const float`
