# label

**Category:** Function

## Syntax

```pinescript
label(x) → series label
```

## Description

Casts na to label

## Arguments

- **`x`** `series label` — The value to convert to the specified type, usually [na](../variables/na.md).

## Returns

The value of the argument after casting to label.

**Return type(s):** `series label`
