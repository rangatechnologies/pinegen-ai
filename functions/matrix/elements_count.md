# matrix.elements_count

**Category:** Function

## Syntax

```pinescript
matrix.elements_count(id) → series int
```

## Description

The function returns the total number of all matrix elements.

## Arguments

- **`id`** `any matrix type` — A matrix object.

**Return type(s):** `series int`
