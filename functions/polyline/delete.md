# polyline.delete

**Category:** Function

## Syntax

```pinescript
polyline.delete(id) → void
```

## Description

Deletes the specified [polyline](../../types/polyline.md) object. It has no effect if the `id` doesn't exist.

## Arguments

- **`id`** `series polyline` — The polyline ID to delete.

**Return type(s):** `void`
